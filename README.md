# 中正大學 國三忠 家庭日｜電子相簿

2026.11.08 福智國中國三忠班家庭日的水彩風電子相簿。

- 封面使用家庭日水彩合照
- 仿真翻書動畫（橫式雙頁、直式單頁），開啟時提示建議橫式觀賞
- 任何人都可上傳照片／影片，檔案存放在 lei6912@gmail.com 的 Google 雲端硬碟
- 「展開全部」一鍵檢視所有照片與影片（可篩選、放大、播放影片、下載原檔）
- 上傳視窗可貼上 YouTube 影片連結（公開或「不公開」），在相簿內用 YouTube 播放器觀看；連結以小檔案形式存在同一個雲端資料夾，刪除該檔即可移除

## 架構

| 部分 | 位置 | 說明 |
|---|---|---|
| 網頁 | GitHub Pages（本 repo） | `index.html`、`style.css`、`app.js`、`config.js` |
| 後端 | Google Apps Script（`gas/Code.gs`） | 以部署者身分讀寫雲端硬碟資料夾；照片設為「知道連結者可檢視」 |

## 一次性設定（約 5 分鐘，需用 lei6912@gmail.com 登入）

1. 開啟 <https://script.google.com> → **新增專案**，專案名稱可取「家庭日電子相簿」。
2. 刪掉預設內容，把 [`gas/Code.gs`](gas/Code.gs) 全部貼上 → 存檔。
3. 上方函式選單選 **setup** → **執行** → 依畫面授權（出現「Google 尚未驗證這個應用程式」時點「進階」→「前往…（不安全）」→ 允許）。
   執行完成後，雲端硬碟會出現資料夾「國三忠 家庭日 電子相簿 2026.11.08」。
4. 右上 **部署** → **新增部署作業** → 齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   → **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。
5. 把網址貼到 `config.js` 的 `apiUrl`（或直接交給 Claude 更新）。

### 選用：上傳通關密語
Apps Script 專案 → **專案設定** → **指令碼屬性** → 新增屬性 `UPLOAD_KEY`，值填密語。設定後上傳時需輸入密語。

### 之後若修改 Code.gs
要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址才不會變。

## 備註
- 照片依拍攝時間排序；也可以直接把照片丟進雲端硬碟資料夾，相簿會自動出現。
- 影片剛上傳時，Google 需要幾分鐘轉檔才能播放。
- 上傳採 5MB 分段傳送，大影片也能上傳，但上傳時請保持頁面開啟。
